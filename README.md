# 👨‍💻 Pedro R Ferreira
---
**`Desenvolvedor Backend`**

Sou desenvolvedor Backend, atualmente trabalho com JavaScript/TypeScript com o framework NestJs para a construão de APIs. Utilizo o banco de dados PostgreSQL e Docker para o desenvolvimento de aplicações.

Tenho experiência com desenvolvimento de APIs RESTful, autenticação e autorização, integração com sistemas externos e gerenciamento de banco e dados.

Tenho experiência também com Python e Django, com o framework Django Rest Framework.

Trabalho atualmente como desenvolvedor Backend na plataforma "[VIDA](https://www.fortaleza.ce.gov.br/noticias/plataforma-vida-disponibiliza-dados-de-acidentes-de-transito)"(STB Tecnologias).

Trabalhei como Desenvolvedor Frontend(Lead Dell), aprimorando minhas habilidades na criação de interfaces para WEB, implementações com acessibilidade e responsividade.
